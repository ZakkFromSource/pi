# Create Or Revise A Skill

Read for a new skill or a revision based on clarified reusable behavior. For
an existing source package, use the Port procedure first when its behavior
must be understood before designing the result.

Use the agreed contract and relevant current evidence. A narrow revision may
need only a focused edit and validation; do not redesign the whole package.
Identify realistic requests that should and should not activate the skill,
including nearby skills with similar names or subjects.

Choose support files for concrete value:

- Prose carries judgment, decisions, and non-obvious operational constraints.
- References hold substantial branch procedures, examples, templates, or
  checklists that a run needs only conditionally.
- Scripts suit maintained, repeatable mechanics that are safer or clearer
  than generating the operation each time.
- Assets supply reusable inputs, fixtures, or templates needed by the task.

This branch is ready for drafting when the behavior, selection boundary,
acceptance evidence, and justified file shape are clear. Reuse existing
resources and preserve valid constraints during revision.
